# nitinbandgar.github.io

**The content pipeline** of First Principles Studio: how every film, Short, Hindi version and interactive experience
is made in code, organised by format, in plain language, with a production tracker.

- **Pick a format:** explainer, evidence (In Context), business, Imagine (past/future), Shorts, Hindi version,
  Lab experience, interactive figure. Each has its rules, steps, commands, a "done when" list and a ready-to-copy
  Claude Code prompt.
- **How every film is made:** the seven stages of the `/make-film` skill (director, art director, animator, render
  engineer, critic, repair, delivery), with the creator's approval gates.
- **Ingredients, quality rules, roadmap, ideas reviewed, where things live.**
- **Production tracker:** saved in the browser (`localStorage`), with JSON export and import.

Live at https://nitinbandgar.github.io/
